# Pho Kentish

Website for **Pho Kentish** — Vietnamese street food in Kentish Town (formerly Pho Ta Vietnamese Street Food).

Built with a similar structure to [photarestaurants.com](https://www.photarestaurants.com/): home, menu, visit, reservations, FAQ, food safety, and legal pages. Food and venue photography is from the original Pho Ta Vietnamese Street Food Kentish Town gallery.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
